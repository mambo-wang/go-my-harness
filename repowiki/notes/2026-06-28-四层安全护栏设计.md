## 背景

Agent 需要执行 Shell 命令和读写文件，但直接执行存在严重安全风险（误删文件、无限循环、输出爆炸等）。

## 决策

采用四层安全护栏设计：
1. **工作目录隔离**：所有工具操作限制在 workspace/ 目录内
2. **超时控制**：Bash 命令 30 秒超时，防止无限执行
3. **输出截断**：工具输出超过 8000 字节自动截断
4. **错误自修正**：工具执行错误不崩溃，而是反馈给 LLM 让其自行修正

## 备选方案

- **Docker 沙箱**：用容器隔离 — 放弃，因为增加了部署复杂度，单机场景不需要
- **权限白名单**：只允许特定命令 — 放弃，因为过度限制了 Agent 的能力

## 影响

Tools 模块每个工具实现都内置了安全检查，而非集中在 Engine 层。这使得安全策略可以针对每个工具的特性定制（如 EditFileTool 的模糊匹配就是独有的容错机制）。
